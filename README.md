# Simple Calculator 🧮

A simple calculator built with **HTML, CSS, and JavaScript**. This project provides a clean calculator interface for performing basic arithmetic operations directly in the browser.

## Features

* Addition `+`
* Subtraction `-`
* Multiplication `×`
* Division `/`
* Modulo `%`
* Decimal numbers `.`
* Clear display with `AC`
* Error handling for invalid calculations
* Simple and clean calculator interface

## Technologies Used

* **HTML5** — Structure of the calculator
* **CSS3** — Styling and layout
* **JavaScript** — Calculator logic and functionality

```bash

```

### 2. Open the project

Open the project folder in **VS Code** or another code editor.

### 3. Run the calculator

Open `index.html` in your web browser.

You can also use **Live Server** in VS Code for easier development.

## How It Works

The calculator uses JavaScript functions to control the display and perform calculations.

* `clearDisplay()` clears the calculator display.
* `toDisplay()` adds numbers or operators to the display.
* `calculate()` evaluates the entered expression and displays the result.
* Invalid calculations are displayed as `ERROR`.

## Example

20 - 8 = 12

6 × 4 = 24

20 / 5 = 4
